# hyper_copy

`hyper_copy` は、ファイルコピーと同時にテキスト（およびファイル名）の置換を行うコマンドラインツールです。
「Preserve Case（大文字小文字の維持）」機能がデフォルトで有効になっており、置換元の文字列のケース（キャメルケース、パスカルケース、大文字、小文字など）に合わせて、置換後の文字列のケースも自動的に調整されます。

## 特徴

- ファイルの中身をコピーしながら文字列置換
- 複数の置換ルールを同時指定可能 (`--from`, `--to`, `--from2`, `--to2` など)
- 置換元のケース（大文字・小文字・パスカルケース・キャメルケース）を自動判定して維持
- ディレクトリへの一括コピー対応（ファイル名も自動的に置換されます）
- 誤作動を防ぐための安全な上書き防止機能（事前チェックによる安全な中断）

## 前提条件

- Ruby がインストールされている Windows 環境

## インストール

本ディレクトリ（`hyper_copy`）にある以下のファイルを、パスの通ったディレクトリ（環境変数 `PATH` に含まれるフォルダ）に配置することで、どこからでも `hyper_copy` コマンドとして呼び出せるようになります。

- `hyper_copy.rb` (本体)
- `hyper_copy.cmd` (Windows 用コマンド実行ラッパー)

## 使い方

### 基本的な使い方

```sh
hyper_copy --from FooBar --to AaaBbb Foo.cs Aaa.cs
```
`Foo.cs` の中身の `FooBar` 関連の文字列を `AaaBbb` に置換し、`Aaa.cs` として保存します。

### 複数の置換ルールを指定

`--from` と `--to` は複数指定することが可能です。わかりやすく `--from2`, `--to2` のように連番をつけることもできます。

```sh
hyper_copy --from FooBar --to AaaBbb --from2 フー --to2 バー Foo.cs Aaa.cs
```

### ディレクトリへの一括コピー

最後の引数に既存のディレクトリを指定すると、複数のファイルをまとめてコピーできます。
この際、**ファイル名に対しても置換ルールが適用されます**。

```sh
hyper_copy --from Foo --to Aaa Foo.cs Bar.cs ../tmp
```
この場合、以下のようにコピーされます。
- `Foo.cs` -> `../tmp/Aaa.cs` (ファイル名・中身ともに置換)
- `Bar.cs` -> `../tmp/Bar.cs` (中身のみ置換)

### 上書きの防止と強制上書き (-f)

デフォルトでは、コピー先に1つでも既存ファイルが存在する場合、**ファイルは一切変更されずに処理全体が失敗**します。

```sh
$ hyper_copy --from Foo --to Aaa Foo.cs Bar.cs .
Cannot overwrite existing file(s): Aaa.cs
Use -f or --force to overwrite.
```

既存ファイルを上書きしたい場合は `-f` または `--force` オプションを付与してください。

```sh
$ hyper_copy -f --from Foo --to Aaa Foo.cs Bar.cs .
Foo.cs -> Aaa.cs
Bar.cs -> Bar.cs (overwrite)
```

## Preserve Case（大文字小文字の維持）について

置換ターゲット (`--to` に指定した文字列) が `AaaBbb` の場合、元のテキストの書き方に応じて以下のようにスマートに置換されます。

| 元ファイル内の文字列 | 置換後の文字列 | 備考 |
| --- | --- | --- |
| `FooBar` | `AaaBbb` | パスカルケース (先頭大文字に追従) |
| `fooBar` | `aaaBbb` | キャメルケース (先頭小文字に追従) |
| `FOOBAR` | `AAABBB` | すべて大文字 |
| `foobar` | `aaabbb` | すべて小文字 |

※ 日本語（例: `フー` -> `バー`）などの文字の大小が存在しない文字については、そのまま置換されます。
